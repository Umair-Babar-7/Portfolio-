# Technology logos

Original, unmodified technology marks are bundled locally so they work without an external image service. Brand colors are preserved, with neutral light plates for visibility in both themes.

- Python, Scikit-Learn, NumPy, Pandas, Matplotlib, Jupyter, Git, and GitHub: [Devicon v2.17.0](https://github.com/devicons/devicon/tree/v2.17.0/icons), using each technology's `*-original.svg` asset.
- Seaborn: the project's [official v0.13.2 logo mark](https://github.com/mwaskom/seaborn/blob/v0.13.2/doc/_static/logo-mark-lightbg.svg).

The Devicon MIT license and Seaborn BSD license are included alongside the assets. All trademarks remain the property of their respective owners; inclusion identifies technologies used in the portfolio and does not imply endorsement.
