# Bundled fonts

These Latin variable font subsets are served locally using `next/font/local`, so rendering and production builds do not depend on Google Fonts access.

- Inter: `@fontsource-variable/inter` 5.3.0, `files/inter-latin-wght-normal.woff2`.
- Space Grotesk: `@fontsource-variable/space-grotesk` 5.3.0, `files/space-grotesk-latin-wght-normal.woff2`.

Source: the Fontsource packages on the official npm registry. Archive SHA-512 integrity was verified before extraction. The corresponding SIL Open Font License files are included alongside the fonts.
